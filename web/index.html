测试参数

对应 cfdata 命令行参数，任务执行时逐项传入
达标结果数上限；9999=不限制。设小（如 50）达标够数后提前结束
测速完成后每个源单独提取速度最快的前 N 个（默认 5），输出 top_by_source.txt
源获取/测试失败时自动重试次数（默认 3，0 = 不重试）
两次尝试之间的等待时间，默认 5 秒
无交互环境下关闭检测会导致任务被取消

历史节点复测

每轮测速的达标节点自动入池（滚动窗口并集）；开启复测后，池内节点将作为第一个"源"参与下轮测试，与 API 源结果合并排名，API 源全部失效时仍可兜底出结果
池为空时自动跳过，不影响任务
超出后挤出最近速度最慢的节点（默认 250）
只保留最近 N 次运行中出现过的节点（默认 5）
连续 K 次复测不达标即移出池（默认 3）
